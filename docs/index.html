Goed UI

用 Go 写桌面界面。写法对齐 Vue 3 的 h(type, props?, children)：组件 setup 一次，渲染函数每次重绘返回一棵虚拟节点树。应用层只从 github.com/goedui/goed/ui 取 API。

快速开始

根组件和 CreateApp 包住的那一层都要 Style.Flex: 1，否则窗口按内容高度排，状态栏会被顶出去。

var App = ui.Component(func(ctx *ui.SetupContext) func() *ui.VNode {
    n := ui.Ref(0)
    return func() *ui.VNode {
        return ui.VStack(ui.Props{Style: ui.Style{Flex: 1, Padding: 16, Gap: 8}},
            ui.Text("点击了 ", n.Get(), " 次"),
            ui.Button(ui.Props{OnClick: func() { n.Set(n.Get() + 1) }}, "点我"),
        )
    }
})

func main() {
    ui.CreateApp(App).Title("demo").Size(960, 640).Theme("light").Run()
}
Run() 必须在主 goroutine。后台改 UI 用 runtime.Dispatcher + platform.Post；测试里 Post 为 nil 时只入队，要自己 Drain()。

编程模型

组件

Component(setup) 在创建时跑一次 setup，返回的函数是渲染函数。状态放 Ref，改值后请求重绘。生命周期在 SetupContext 上：OnMounted / OnUnmounted / Invalidate / Props / Attr / Children。Attr(key) 按名字读少数注入字段：state / dispatcher / focus / path / label；Children() 是默认 slot。

OnMounted 发生在第一次渲染之后，早于布局。要读 X/Y/W/H 用 SetAfterPaint，那时本帧布局已经写进节点。子组件实例按 vnode 路径缓存跨帧复用，Props.Key 参与调和（节点上用 .WithKey("id") 设 key）。没有 computed / watch / emit / 具名 slot，也没有 VNode diff——脏时整棵应用树重建。

节点

H(type, props?, children...) 是底层工厂。VStack / HStack 的 children 可以是 *VNode 或 []*VNode，不要把 []any 和 Props 一起 ... 展开。Button 的签名是 (props?, label)，不是通用 children 工厂。

颜色 A == 0 表示未设置，不要用全 0 RGB 当黑色。单位是 DIP，96 DIP = 1 英寸。X/Y/W/H 只在 PaintTree 之后有效。

浮层

popover、dialog 和 ctxmenu（右键面板）是 Overlay：后绘制、后命中。新浮层必须把 tag 加进 runtime.OverlayTag，否则会被后面的内容盖住、点不到。键盘顺序是 dialog → ctxmenu → popover → 焦点 → 其余；ctxmenu 排在 popover 前，是为了让 Esc 先关最后打开的那一层。

布局

流式布局由 VStack / HStack 完成。第一个 layer 孩子铺满，其余按自然尺寸叠在 (x, y)。文本节点必须给够 Height，否则字形下半会被裁掉。

Textarea 多行输入

        if e.Ctrl && e.Key == ui.KeyA && e.Down { ui.SelectAllStay(node); return true }

MenuBar 菜单

不要在应用里手写 Button + Popover 菜单。顶层菜单用 MenuBar，右键用 ContextMenu。两项都用 MenuItem，Sep 画分隔线，Shortcut 用制表符对齐。

Dialog 对话框

铺满父级的半透明遮罩加居中卡片。Esc 和点击遮罩走 OnClose。确认框把 Modal 设为 true（内部写入 dismiss=false），避免点遮罩关掉。遮罩吃掉滚轮，不会穿透到下面的编辑区。

    ContentWidth: 360, Modal: true,   // 卡片宽；点遮罩不关

Scroll 滚动

自带滚动条的容器，按 ID（或 Key）存偏移。普通盒子在 VStack / HStack 上直接写 OverflowY: ui.OverflowAuto 也能滚（通用溢出路径，按节点 id 记偏移）；scroll 控件有自己的布局，不走那条路。滚轮到头会继续向外冒泡。

ui.Scroll(ui.Props{ID: "list", WideBar: true, Style: ui.Style{Flex: 1}}, rows...)
y := ui.ScrollOffset("list")
ui.ScrollBy("list", -1)
函数说明
ScrollOffset / SetScrollOffset读或写纵向偏移
ScrollMax / ScrollBy可滚上限；按滚轮格滚动，正值向上
WideBarProps 字段。留出 22 DIP 滑槽，避免细滚动条盖住最后一列
ContentHeight / ScrollBottomGap / ScrollToEnd内容高度 / 距底部 DIP / 滚到最底。在 components 包，未从 ui 再导出；流式贴底用 ScrollBottomGap(id)==0 → ScrollToEnd(id)

Table 表格

子节点是行，行的子节点是单元格。列宽取该列自然宽度的最大值，再按行的 flex 分剩余空间。空单元格仍然占一列。

ui.Table(
    ui.HStack(ui.Text("名称"), ui.Text("类型"), ui.Text("非空")),
    ui.HStack(ui.Text("id"), ui.Text("INTEGER"), ui.Text("是")),
)

Canvas 画布

    Style: ui.Style{Width: 800, Height: 600},
    OnPaint: func(ctx renderer.Context, x, y, w, h float32) {

样式与主题

零值字段走主题。A == 0 的颜色是未设置。内置 light / dark（色板对齐 VS Code Default Light+ / Dark+），自定义主题用 RegisterTheme 后 CreateApp(...).Theme("name")，或直接 UseTheme。运行中切换 SetTheme，读当前用 CurrentTheme，按名取用 LookupTheme（未知名回退 Default=light）。

Style 字段说明
FontSize / FontFamily / Weight文字。Weight 是字重整数
Color / Background / Border / Radius前景、背景、边框、圆角
Gradient实际挂在 Props.Gradient（不在 Style 里）：GradientFill{From, To, Vertical}。端点 A==0 由绘制端回退
Shadow实际挂在 Props.Shadow：ShadowStyle{Blur, OffsetY, Color}。Color A==0 时按黑色低透明度
Theme 字段说明
Name / Dark登记名；Dark 决定窗口边框和禁用色回退
Background / Foreground窗口底和正文
Titlebar / TitlebarForeground / TitlebarHover / TitlebarInactive / CloseHover框架标题栏
Separator / Button / ButtonForeground / ButtonHover / ButtonPressed分隔线和按钮
Disabled / DisabledForeground未设置时按 Dark 回退，文字对比度满足 WCAG AA
FontFamily / FontSize / Padding主题默认文字和内边距
 
ui.RegisterTheme(ui.Theme{Name: "paper", FontSize: 13, Background: ui.RGB(250, 248, 244)})
ui.SetTheme(ui.LookupTheme("paper"))  // 运行中切换

按键

常量：KeySpace KeyEnter KeyEscape KeyBackspace KeyTab KeyHome KeyEnd KeyLeft KeyUp KeyRight KeyDown KeyPageUp KeyPageDown KeyDelete，字母导出的是 KeyA KeyC KeyF KeyL KeyN KeyO KeyP KeyS KeyT KeyV KeyW KeyX KeyY KeyZ，另有 KeyF1 KeyF11。KeyEvent 带 Key Char Ctrl Shift Alt Down，KeyHandler 返回 true 表示已消费。

纯 keyup 分发给树上的 onKeyUp（游戏「按住移动」维护按键状态），不影响只认 keydown 的输入框。输入法：Windows 把组合串交给焦点控件的 onComposition，上屏走 onTextInput——Input / Textarea 已内建，应用层一般不用接。

使用约定

  • 新控件写在 ui/components，init 里 renderer.Register(tag, Widget)，再从 ui/ui.go 导出。
  • 不要在应用里手写按钮菜单、1px Box 分隔线或胶囊标签，用 MenuBar、Select、Divider、Dialog、Tabs。
  • 新浮层 tag 必须加入 runtime.OverlayTag（目前是 popover / dialog / ctxmenu）。
  • 跨线程改窗口走 Post。直接跨线程 SetWindowPos 会死锁。测试里 Post 为 nil 只入队，要 Drain()。
  • 只拼 runtime.H("button") 而不导入 components 时，Paint 没有 widget。mock renderer.Context 必须实现 DrawPixels。
  • 进程级状态（Select 开合、Input 编辑状态、Scroll 偏移）按 id 存 map，测试必须 Cleanup。
  • 宿主：Windows（Direct2D）、Linux（X11）、Web（Canvas 2D）。macOS 及其它平台 run_stub.go 直接报错。Web 没有 SetWindowSize，画布尺寸由页面决定，CaptionButtons() 为 false。
