开始

简介

goed UI 是用 Go 写的声明式桌面 UI 引擎：用 VNode 描述界面，引擎负责布局、绘制、输入与命中，不写 HTML 也不依赖浏览器。

设计取向

  • 形状对齐 Vue 3：h(type, props?, children...)、Component(setup)、Ref，会写 Vue 就能上手。
  • 绘制走系统原生：Windows 上是 Direct2D + DirectWrite（GPU 加速、ClearType、原生 DPI），Linux 是 X11，Web 是 js/wasm。
  • 没有运行时解释器：Component.setup 只执行一次，返回的函数每次重绘产生新的节点树；引擎按 Key / ID 调和。
  • 单位是 DIP：96 DIP = 1 英寸，与系统缩放无关，高 DPI 下布局数字不用改。

一个应用由什么组成

GO
package main

import "github.com/goedui/goed/ui"

// 1. 根组件：setup 只跑一次，返回渲染函数。
var App = ui.Component(func(_ *ui.SetupContext) func() *ui.VNode {
	return func() *ui.VNode {
		return ui.VStack(
			ui.Props{Style: ui.Style{Flex: 1, Padding: 20, Gap: 12}},
			ui.Text(ui.Props{Style: ui.Style{Height: 24}}, "你好，goed UI"),
			ui.Button(ui.Props{OnClick: func() {}}, "点击"),
		)
	}
})

func main() {
	// 2. 应用外壳：窗口标题、尺寸、主题。
	if err := ui.CreateApp(App).
		Title("示例").
		Size(800, 600).
		Theme("light").
		Run(); err != nil {
		panic(err)
	}
}

  • Linux：X11 后端。

安装

goed UI 是库，不是可执行命令，也不需要 go install。给已有的 Go 模块加一行依赖即可。

要求

  • Go 1.23 及以上。
  • 一个已有的 Go 模块；没有就先 go mod init example.com/myapp。

go get github.com/goedui/goed/ui@latest

开始

快速上手

从空目录到一个能点的计数器，大约 30 行。

最小可运行程序

GO
package main

import "github.com/goedui/goed/ui"

var Counter = ui.Component(func(_ *ui.SetupContext) func() *ui.VNode {
	// setup 里创建状态：Ref 一改，界面就重绘。
	count := ui.Ref(0)
	return func() *ui.VNode {
		return ui.VStack(
			ui.Props{Style: ui.Style{Flex: 1, Padding: 24, Gap: 12, Background: ui.RGB(255, 255, 255)}},
			ui.Text(ui.Props{Style: ui.Style{Height: 32, FontSize: 24, Weight: 600}}, "Hello, goed UI"),
			ui.Text(ui.Props{Style: ui.Style{Height: 24}}, "点击次数：", count.Get()),
			ui.Button(ui.Props{OnClick: func() { count.Set(count.Get() + 1) }}, "点我"),
		)
	}
})

func main() {
	if err := ui.CreateApp(Counter).Title("Hello").Size(600, 400).Run(); err != nil {
		panic(err)
	}
}

三条容易踩的规矩

  1. 根节点要 Style.Flex: 1，否则走「主题 padding + 自然高度」分支，界面缩在顶部。
  2. Run() 必须在主 goroutine 调用；跨线程改窗口尺寸走 ui.SetWindowSize（内部会 Post）。
  3. 文本节点给够 Style.Height，不然 DirectWrite 会把字形下半裁掉。
基础

节点与子内容

ui.H 是通用节点工厂，子内容可以是节点、节点数组或任意会被拼成文本的值。

构造节点

GO
// 通用工厂：标签名是引擎内置的控件名
ui.H("box", ui.Props{Style: ui.Style{Flex: 1}}, child)

// 便捷控件：第一参数可以是 Props，也可以是纯子内容
ui.Box(ui.Props{Style: ui.Style{Padding: 16}}, child)
ui.Text(ui.Props{Style: ui.Style{Height: 22}}, "你好，", name)

// 自定义组件（*ui.ComponentDef）
ui.H(editor.View, ui.Props{Style: ui.Style{Flex: 1}, Path: path})

子内容规则

  • children 可以是 *VNode、[]*VNode，或会被格式化成文本的值（数字、Ref、fmt.Stringer）。
  • 不要写 children... 展开一个 []any 再拼 Props —— 类型对不上，编译直接失败。
  • ui.Button 是例外：签名是 Button(props?, label)，第二个参数是文案，不接子节点。

Key 与 ID

  • 列表项用 node.WithKey("id") 或 ui.Props{Key: "id"}，重排时实例状态跟着走。
  • ui.Props.ID 是有语义的全局 id：滚动位置、编辑状态、焦点、Select 开合、浮层锚点都按它存。
  • node.ID() 读回 id（没写时按结构生成）。

找节点

GO
n := ui.FindByID(ui.LayoutRoot(), "main-input")
if n != nil {
	ui.SetFocus("main-input")
}

受控与回填

值类控件（Input、Textarea、Select、Switch、Checkbox、Slider、Tabs）都是受控的：回调收到新值后，应用更新自己的状态，下一次渲染把新值传回 Value。控件只记「编辑中间态、滚动、开合」这类内部状态。

GO
enabled := ui.Ref(false)
return ui.Switch(ui.Props{
	ID:       "notify",
	Value:    enabled.Get(),
	OnChange: func(on bool) { enabled.Set(on) },
})

回调签名

字段类型
OnChangefunc(string) / func(bool) / func(float64)，按控件而定
OnInput、OnSubmit、OnBlurfunc(string) / func()
OnSelectfunc(string)；ItemMenu 收到 MenuRow.ID，Markdown 收到链接 URL
OnClose、OnOpenfunc() 或 func(bool) / func(string)，见各控件页
OnKeyDownfunc(ui.KeyEvent) bool，返回 true 表示已处理
OnContextMenufunc(x, y float32)，客户区 DIP 坐标
OnPaintfunc(renderer.Context, x, y, w, h float32)
OnClick 只表示「这块矩形可点」，不是组件事件冒泡：谁在最上面就归谁，不会传给父级。
基础

Style

Style 对应 CSS 的行内样式：零值表示「没写」，走主题默认；每个节点都能带一份，不限于某个控件。

Padding Margin Gap内边距、外边距、子项间距。
MarginAutomargin: 0 auto：固定宽度的块在父级内容区里水平居中。
MarginLeftAutomargin-left: auto：横排里吸收左侧剩余空间，把自己与后面的兄弟推到最右。

Position 与 Inset

Top: 0 这类写法默认被当成「没写」，因为零值无法区分。要真的钉在 0 上，必须同时写位标志：

GO
// 铺满父级宽度（左 0 + 右 0 = 拉满）
ui.Text(ui.Props{Style: ui.Style{
	Position: ui.PositionAbsolute,
	Inset:    ui.InsetLeft | ui.InsetRight,
	Left:     0, Right: 0, Top: 120,
	Align:    ui.Center,
}}, "居中一行")

绝对定位的包含块

  • 最近的 relative / absolute 祖先的 padding 边；没有就相对内容区。
  • 对边都写了且没写 Width / Height 时，该轴被拉满。
  • 绝对定位不占父级空间，父级的测量不会把它的尺寸算进去。

颜色

GO
ui.RGB(255, 255, 255)           // 不透明
ui.RGBA(0, 0, 0, 0)              // 全透明 —— 注意 A == 0 在 Style 里表示「未设置」
ui.Style{Background: ui.RGB(0xFA, 0xFA, 0xFA), Radius: 6}
颜色的 A == 0 一律按「未设置」处理。想画透明底请用 ui.RGBA(r, g, b, 1) 这种接近 0 但非 0 的 alpha。

渐变与阴影

raised := ui.Props{
	Style:    ui.Style{Height: 40, Radius: 8},
	Gradient: &ui.GradientFill{From: ui.RGB(22, 93, 255), To: ui.RGB(0, 180, 42), Vertical: false},
	Shadow:   &ui.ShadowStyle{Blur: 12, OffsetY: 4},

基础

组件与状态

ui.Component(setup) 的 setup 只跑一次，返回的渲染函数每次重绘都会重新执行；Ref 是跨帧保存的状态。

结构

GO
var Panel = ui.Component(func(ctx *ui.SetupContext) func() *ui.VNode {
	// 这里只执行一次：状态、订阅、计时器放这儿
	open := ui.Ref(false)
	ctx.OnMounted(func() { /* 首次挂载 */ })
	ctx.OnUnmounted(func() { /* 卸载清理 */ })

	return func() *ui.VNode {
		// 每次重绘都会执行：只描述界面，别在这里建状态
		return ui.VStack(ui.Props{Style: ui.Style{Gap: 8}},
			ui.Button(ui.Props{OnClick: func() { open.Set(!open.Get()) }}, "切换"),
			ui.Text(ui.Props{Style: ui.Style{Height: 22}}, "open = ", open.Get()),
		)
	}
})

Ref

  • ui.Ref(v) 返回 *runtime.Ref[T]，Get() / Set(v)；Set 会请求重绘。
  • Set 一定会请求重绘：值没变也会（这样 Ref 可以当「脏标记」用）。
  • Ref 会实现文本输出，可以直接塞进 ui.Text 的子内容。

SetupContext

方法用途
Props()组件收到的 ui.Props（H(Comp, props) 里那份）。
Attr(key) / String(key)读任意属性和字符串属性。
Children()传给组件的子节点。
Invalidate()手动请求重绘。
OnMounted / OnUnmounted挂载与卸载钩子。

重绘时机

事件驱动的界面只在「脏了」的时候重绘：Ref.Set、输入、布局变化、窗口尺寸改变都会标脏。实时动画用 CreateApp(...).Continuous(true)，此时根组件每帧重建 —— 别在那种模式下写重活。

基础

布局与命中

布局单位是 DIP；节点的 X / Y / W / H 只在绘制完一帧之后才有效。

容器怎么排子节点

容器排法
VStack纵向依次排；Gap 间隔；子项 Flex 分剩余高度。
HStack横向依次排；Gap 间距；子项 MarginLeftAuto 推到最右。
Wrap横向流式，放不下换行；子项保持自然尺寸。
Box子节点叠在同一块内边距区域（不是文档流）。
layer（ui.H("layer", ...)）第一个孩子铺满，其余按自然尺寸叠在左上角。
Table行是子节点，行内子节点是单元格；列宽取各行自然宽最大值。

浮层的顺序

popover、dialog、contextmenu、itemmenu、tooltip 都是 Overlay：最后绘制、最先命中。键盘事件顺序是 dialog → popover → 焦点控件 → 其余。

命中与悬停

  • 只有带 OnClick / OnPointerDown / OnContextMenu / OnMouseEnter / OnMouseLeave 的节点进命中表。
  • 命中取最上层那个节点，不冒泡：父子都绑了回调时只触发子节点。
  • renderer.PointerIn(x, y, w, h) 可以在绘制回调里问「指针是否在这块矩形里」，renderer.PointerDown() 问按下态。

测量与绘制是两趟

GO
// 依赖布局结果的收尾动作放这里：本帧绘制完，X/Y/W/H 已经是新值
ui.SetAfterPaint(func() {
	x, y, w, h, ok := ui.FocusedCaretRect()
	_ = x
	_ = y
	_ = w
	_ = h
	_ = ok
})
合成点击（自动化测试）之前先画一遍：坐标没算出来之前点谁都点不中。
基础

文本与字体

ui.Text 是最基础的节点：子内容按顺序拼成一段文字，字体、颜色、对齐都由 Style 控制。

基本用法

GO
ui.Text(ui.Props{Style: ui.Style{
	Height: 24, FontSize: 14, Weight: 500, Color: ui.RGB(70, 78, 90),
}}, "你好，", "goed UI", count)

高度必须给够

文本节点的高度参与裁剪：写着 Height: 16 却用 14px 字号，字形下半会被裁掉。经验值是 字号 × 1.4 以上，或者干脆不写 Height，让测量结果决定。

换行与省略

写法效果
不写 Nowrap按可用宽度自动折行，高度随行数增长。
Nowrap: true单行，不折行（超宽会被父级裁掉）。
Ellipsis: true单行超宽时尾部省略，通常和 Nowrap 一起用。

对齐

节点的 Style.Align 同时决定「子节点怎么摆」和「文字在盒子里怎么对」。文本节点自己写了 Align 才算数；父级写 Align: ui.Center 不会让所有 Text 变居中。

富文本与 Markdown

  • ui.RichText(props, runs...) 支持行内加粗、斜体、行内代码、下划线、删除线、链接点击，折行时格式不断。
  • ui.Markdown(props, source) 解析 GFM：标题、段落、列表、表格、代码块（带高亮）、链接。
基础

主题

主题是一组命名视觉配置：底色、前景、标题栏、按钮三态、禁用态、字体与 padding。零值颜色回退到内置默认。

内置主题

GO
// 主题名："light" / "dark"，未知名字回退默认
app := ui.CreateApp(App).Title("示例").Theme("light")
if err := app.Run(); err != nil {
	panic(err)
}

// 直接给一份主题值（等价于按名字取内置主题）
ui.CreateApp(App).UseTheme(ui.LookupTheme("dark")).Run()

派生一份自己的主题

GO
func Theme() ui.Theme {
	t := ui.LookupTheme("light")
	t.Name = "my-app"
	t.FontFamily = "Microsoft YaHei UI"
	t.Background = ui.RGB(0xFA, 0xFA, 0xFA)
	t.Button = ui.RGB(0x00, 0xC3, 0x75)
	t.ButtonHover = ui.RGB(0x06, 0xAE, 0x66)
	t.ButtonPressed = ui.RGB(0x05, 0x9B, 0x58)
	return t
}

ui.CreateApp(App).UseTheme(Theme()).Run()

字段影响
Background Foreground默认底色与文字色。
Titlebar TitlebarForeground TitlebarHover TitlebarInactive CloseHover框架标题栏。
Separator分隔线、边框、未选中标签的底色。
Button ButtonForeground ButtonHover ButtonPressed主按钮三态。

组件 / 通用

按钮 Button

可点击按钮。签名是 ui.Button(props?, label)；底色默认取主题，写死 Style.Background 会关掉悬停反馈。

示例

GO
ui.Button(ui.Props{OnClick: save}, "保存")

ui.Button(ui.Props{Variant: "secondary", Icon: "save", OnClick: save}, "另存为")

ui.Button(ui.Props{Disabled: true}, "不可用")

字段

字段说明
Variant不写＝主按钮（主题 Button 三态）；secondary / ghost 是次要与幽灵。
Icon左侧图标名，走 Glyph 图标集（如 save、trash）。
TextAlign"start" 让文字靠左（菜单项式按钮）；默认居中。
Selected用主题强调色底 + 白字。
Disabled置灰且不吃点击。
StyleWidth / Height / Radius / Background / Color / FontSize / Weight。

尺寸

  • 默认最小高度 32 DIP，水平 / 垂直内边距 16 / 8（可用 Style.Padding 覆盖）。
  • 宽度按文字自然宽 + 内边距；写 Style.Width 就只用它。
  • 圆角走 Style.Radius；0 画直角。
Style.Background 会同时覆盖 hover / pressed 两态（自定义底色时控件不再变色）。想要悬停反馈就把颜色写进主题 Button / ButtonHover / ButtonPressed。

图标 Glyph

单个矢量图标节点：Icon 指定名字，Style.Width / Height 缺省 16 DIP，Style.Color 是笔画色。

矩形容器：按自身 Style 画底色、描边、圆角，子节点排在内边距区域里。它也是最常用的绝对定位包含块。

  • 配合 Position: relative 当绝对定位的包含块（relative 自己仍按文档流占位）。

堆叠 VStack / HStack

最常用的两个容器：VStack 纵向依次排，HStack 横向依次排。子项的 Flex 划分剩余空间，Gap 是间距。

示例

GO
ui.VStack(ui.Props{Style: ui.Style{Flex: 1, Gap: 8, Padding: 12}},
	ui.Text(ui.Props{Style: ui.Style{Height: 22}}, "标题"),
	ui.Button("确定"),
)

ui.HStack(ui.Props{Style: ui.Style{Height: 36, Gap: 8, Align: ui.Center}},
	ui.Text(ui.Props{Style: ui.Style{Height: 22}}, "名称"),
	ui.Input(ui.Props{Style: ui.Style{Flex: 1}, Placeholder: "输入名称"}),
	ui.Button("保存"),
)

剩余空间怎么分

  • 主轴：没有 Flex 的子项按自然尺寸，剩余空间按 Flex 权重分给写了 Flex 的子项。
  • Flex: 1 的根节点铺满客户区；Flex: 0（默认）就是自然尺寸。
  • MarginLeftAuto: true 在 HStack 里把这一项及后面的一起推到最右。
  • Justify 控制主轴对齐（ui.SpaceBetween / Center / End），Align 控制交叉轴。

流式 Wrap

横向流式排列，一行放不下自动换行，等价于 CSS flex-wrap: wrap。子项保持自然尺寸。

示例

GO
ui.Wrap(ui.Props{Style: ui.Style{Width: 400, Gap: 8}},
	ui.Tag(ui.Props{Label: "Go"}),
	ui.Tag(ui.Props{Label: "Desktop"}),
	ui.Tag(ui.Props{Label: "UI"}),
)

规则

  • 行高取该行最高的子项，行内从左往右摆，剩余空间留在右侧。
  • 子节点的 Flex 在 Wrap 里没有意义，会被忽略。
  • 需要「两端对齐」的网格请用 Table 或手写若干 HStack。

叠层 Layer

ui.H("layer", ...)：第一个普通子节点铺满容器，其余按自然尺寸叠在左上角。适合「底图 + 角标」。

示例

GO

	ui.Tag(ui.Props{Label: "预览"}),                          // 叠在左上角
)

和绝对定位的区别

layer 的叠加不要求 Position，但叠加项仍在正常位置（左上角），移位要靠 Margin 或 Style.Left/Top（后者需要 Position: relative 才生效）。要精确钉坐标，用 Box{Position: relative} + 子节点 Position: absolute。

popover / dialog 这类浮层不需要 layer：它们自己就是 Overlay，后绘制、先命中。

表格 Table

按列对齐的网格：子节点是行，行的子节点是单元格。列宽取各行同列自然宽的最大值。

列宽规则

  1. 每列取各行该列的自然宽最大值（MinWidth 作为下限）。

滚动 Scroll

可滚动容器，纵向默认自动。滚动位置按 ID 保存，所以必须给非空且唯一的 ID。

示例

GO

函数说明

ResetScroll(id)丢弃偏移（测试与重建界面用）。

窗口按钮 WindowCaption

窗口右上角的最小化 / 最大化 / 关闭图形。它只负责画，点击由宿主的命中区处理。

示例

GO
// main.go：自绘标题栏
ui.CreateApp(App).
	AppTitleBar(true).   // 应用树从 y=0 起铺满，系统标题栏不再绘制
	Run()

// 顶栏里把三个按钮放最右
ui.HStack(ui.Props{Style: ui.Style{Height: ui.TitleBarHeight, Align: ui.Center, Padding: 0}},
	ui.Text(ui.Props{Style: ui.Style{Flex: 1, Height: 22, Padding: 10}}, "应用名"),
	ui.WindowCaption(),
)

约束

  • 标题栏高度固定 ui.TitleBarHeight（32 DIP），每格宽 ui.CaptionButtonWidth。图形钉在最右三格，不跟父级内边距走。
  • 不要给 WindowCaption 挂 OnClick：宿主把这三格判成 HTMINBUTTON / HTMAXBUTTON / HTCLOSE，挂了会被当成应用控件，系统按钮失灵。
  • 悬停与最大化图标在绘制时读 platform.Frame，不需要应用每帧重建。
  • 浏览器上没有系统按钮，此时返回 nil。
  • 自绘标题栏又要自己画齿轮 / 关闭时，配 HideCaptionButtons() 把三格命中区让出来，关闭调 ui.CloseWindow()。
ui.Frame() 返回 Title / Maximized / 悬停按钮等状态；ui.CaptionButtons() 报告宿主有没有系统按钮。

对话框 Dialog

居中对话框：铺满父级的半透明遮罩 + 居中卡片。默认宽 400 DIP，最小 240。

示例

GO
ui.Dialog(ui.Props{
	Title:       "确认删除",
	Message:     "此操作无法撤销。",
	Modal:       true,      // 点遮罩不关
	ContentWidth: 420,
	OnClose:     func() { dialogOpen.Set(false) },
	OnEnter:     func() { deleteItem() },
},
	ui.HStack(ui.Props{Style: ui.Style{Gap: 8, Justify: ui.End}},
		ui.Button(ui.Props{Variant: "secondary", OnClick: cancel}, "取消"),
		ui.Button(ui.Props{OnClick: confirm}, "删除"),
	),
)

字段

字段说明
Title / Message标题 / 正文（可含换行）。
ContentWidth卡片宽度，默认 400，最小 240。
OnCloseEsc、点击遮罩、关闭按钮。
OnEnterEnter 回调（确认框用来「保存」）。
Modal禁止点击遮罩关闭（内部把 dismiss 置 false）。
CloseOnEnterEnter 自动关闭（没有 OnEnter 时）。

键盘与命中

  • Dialog 是模态层：按键一律先给它，Esc 走 OnClose。
  • 子节点通常是一行按钮；卡片内容由 Title / Message + 子节点组成。
  • 叠在 Dialog 上的滚动区不会抢滚轮 —— 滚轮先落在最上层的 Dialog 子树里。
组件 / 反馈与浮层

浮层 Popover

菜单 / 下拉本体：按锚点定位、靠边时夹回画布并上下翻转、Esc 关闭。MenuBar、Select、ContextMenu 都用它。

示例

GO
ui.Popover(ui.Props{
	ID:      "actions-popup",
	Anchor:  "actions-button",   // 锚点节点 id
	Items:   []string{"复制", "---", "删除"},
	AlignX:  "end",              // start / center / end
	OnSelect: func(v string) { runAction(v) },
	OnClose:  func() { popupOpen.Set(false) },
})

字段

  • Items 里 "-" 或 "---" 画分隔线。
  • AlignX 决定相对锚点的水平对齐。
  • Anchor 为空时继承父级给的盒子（按坐标摆），右键菜单就是这么用的。
  • 选中项回调 OnSelect（显示文本），关闭回调 OnClose。
组件 / 反馈与浮层

富选项菜单 ItemMenu

带图标与说明的下拉面板：可选头部（标题 + 键盘提示）、每项一行（图标 / 名称 / 说明）、可选底栏。

示例

GO
ui.ItemMenu(ui.Props{
	Anchor: "mode-button",
	Title:  "选择模式",
	Hint:   "↑↓ 切换",
	Items: []ui.MenuRow{
		{ID: "fast", Icon: "bolt", Label: "快速", Desc: "更快完成任务", Active: true},
		{ID: "quality", Icon: "sparkle", Label: "高质量", Desc: "优先输出质量"},
	},
	Footer:   "模式设置",
	OnFooter: openModeSettings,
	OnSelect: func(id string) { setMode(id) },  // 收到 MenuRow.ID
})

MenuRow 字段

字段说明
ID Icon Label Desc标识、左图标、主文案、右侧说明。
Active当前项高亮。

交互

  • 根是铺满画布的遮罩：点面板外任意位置都关闭。
  • 卡片贴锚点摆，下方空间不够时翻到上方。
  • Items 为空返回 nil（这一项不存在）。
  • SelectedBackground / SelectedColor 覆盖高亮配色。
组件 / 反馈与浮层

提示 Tooltip

锚在某个节点上方的单行提示，浮在内容之上，不会被锚点盒子裁掉。何时加入节点树由应用决定。

示例

GO
ui.H("layer", ui.Props{Style: ui.Style{Flex: 1}},
	ui.Button(ui.Props{ID: "save-btn", OnClick: save}, "保存"),
	hint.Get(),   // 需要时塞一个 Tooltip 进来
)

hint.Set(ui.Tooltip(ui.Props{Anchor: "save-btn", Label: "保存文件"}))

说明

  • Anchor 是目标节点 id，Label 是提示文字。
  • 它是 Overlay：后绘制、先命中，画在锚点盒子外面。
  • 没有自动的进入 / 离开延迟，悬停时机由应用控制（OnMouseEnter / OnMouseLeave）。
组件 / 反馈与浮层

右键菜单 ContextMenu

在 OnContextMenu 回调里用指针坐标构造：铺满父级的无色遮罩 + 一张按坐标摆的菜单卡片。

示例

GO
menu := ui.Ref[*ui.VNode](nil)

ui.H("layer", ui.Props{Style: ui.Style{Flex: 1}},
	ui.Box(ui.Props{
		Style: ui.Style{Position: ui.PositionRelative, Flex: 1},
		OnContextMenu: func(x, y float32) {
			menu.Set(ui.ContextMenu(ui.Props{
				AtX: x, AtY: y,
				Items: []ui.MenuItem{
					{Label: "复制", Shortcut: "Ctrl+C", Action: copySel},
					{Label: "删除", Action: delSel},
				},
				OnClose: func() { menu.Set(nil) },
			}))
		},
	}, content),
	menu.Get(),
)

字段与约定

  • AtX / AtY 是指针位置（客户区 DIP）。
  • Items 为空时返回 nil；Sep 画分隔线，Action 是点击回调。
  • 点空白、选中菜单项、Esc 都会走 OnClose；OnSelect 在 Action 之后触发。
  • 遮罩铺满父级，所以菜单开着时底下点不到 —— 这是上下文菜单的通行行为。
API

应用与窗口

ui.CreateApp(root) 返回 *ui.App，窗口与主题的配置都挂在它上面；Run() 进入消息循环，必须在主 goroutine 调用。

链式配置

方法说明
Title(string)窗口标题（也是任务栏名）。
Size(w, h)客户区逻辑尺寸，默认 800×600 DIP。
Theme(name) / UseTheme(t)按名字取主题 / 直接用一份主题值。
Continuous(bool)每帧重建根组件；实时动画才开。
AppTitleBar(bool) / HiddenTitlebar()应用自绘标题栏，树从 y=0 铺满。
HideCaptionButtons()让出最右三格的系统按钮命中区（自绘关闭按钮时必须）。
Icon(ico []byte)标准 ICO 窗口图标。
TitleBarStyle(ui.Style)覆盖框架标题栏的底色 / 字色 / 字体。
DropFiles(func([]string))接收拖进窗口的文件路径。
Run()创建窗口并进入消息循环，返回 error。

窗口控制

GO
ui.SetTitle("无标题 - 记事本")
ui.SetWindowSize(1000, 700)      // 窗口就绪前返回 false
w, h, ok := ui.WindowSize()
ui.CloseWindow()                 // 与标题栏关闭同一条路
ui.SetCloseGuard(func() bool {   // 返回 false 表示先别关
	return !doc.Dirty()
})

自绘标题栏

GO
app := ui.CreateApp(App).
	AppTitleBar(true).      // 系统标题栏不再绘制
	HideCaptionButtons()   // 自己画齿轮 / 关闭时让出三格命中区
_ = app.R

// 需要系统按钮就用 ui.WindowCaption()；
// 窗口状态（最大化、按钮悬停）读 ui.Frame()
Run() 必须主 goroutine；SetWindowSize 跨线程安全（内部 Post），但直接调 Win32 SetWindowPos 会死锁。
API

平台能力

剪贴板、文件对话框、拖出文件这些系统能力都走 platform，未实现的平台返回错误而不是 panic。

剪贴板

GO
ui.ClipboardSet("要复制的文本")
text := ui.ClipboardGet()

文件对话框

GO
path, ok, err := ui.OpenFile("打开", "文本文件 (*.txt)|*.txt")
if err != nil { /* 平台不支持 */ }
if !ok { /* 用户取消 */ }

dir, ok, err := ui.OpenFolder("选择目录")
target, ok, err := ui.SaveFile("另存为", "a.txt", "文本文件 (*.txt)|*.txt", ".txt")

拖放

GO
// 拖进窗口
ui.CreateApp(App).DropFiles(func(paths []string) { open(paths[0]) }).Run()

// 拖出窗口（阻塞到用户松手，必须在 UI 线程）
if err := ui.DoDragDropFiles([]string{path}); err != nil {
	/* 平台不支持或路径不在同一父目录 */
}

错误语义

  • 平台没实现的能力返回 err，调用方自行降级。
  • ok == false 表示用户取消，不是错误。
  • DoDragDropFiles 的路径必须同属一个父目录。
API

文本编辑

Input / Textarea 共用一套编辑核心；下面这些入口供状态栏行列、查找定位、弹出菜单里的剪切复制粘贴使用。

焦点

GO
ui.SetFocus("editor")     // "" 表示取消焦点
id := ui.FocusedID()
x, y, w, h, ok := ui.FocusedCaretRect()   // 光标矩形，贴输入法候选窗用

光标与选区

函数说明
CaretLineCol(n)光标的 (行, 列)，0 基，列按 rune 计。
MoveCaret(n, line, col)移动光标并滚入可视范围。
SelectedRange(n)选区字节区间；has == false 表示没有选中。
SelectRange(n, from, to)选中字节区间并滚入可视范围。
SelectAll(n) / SelectAllStay(n)全选 / 全选但不滚动。

编辑命令

GO
ui.EditOp(n, "undo")       // undo redo cut copy paste delete selectall
ui.EditOpID("editor", "copy")  // 菜单回调里拿不到节点时用 id

滚动（多行）

GO
y := ui.TextareaScrollY("editor")
ui.SetTextareaScrollY("editor", 0)
ui.PageTextarea("editor", 1)          // 翻页，dir < 0 向上
lh := ui.TextareaLineHeight("editor")
off := ui.TextareaOffsetY("editor", byteOffset)
切换文档而复用同一个 ID 时先 ui.ResetInputState(id)，否则会带着旧光标与撤销栈。
API

滚动控制

滚动状态按容器 ID 保存。除了 Scroll 控件，任意写了 OverflowY: auto 的容器都适用。

函数

函数说明
ScrollOffset(id)当前偏移（DIP）。
SetScrollOffset(id, v)设置偏移，越界会在下一次布局里夹回。
ScrollMax(id)可滚上限 = 内容高 - 可视高。
ScrollBy(id, delta)相对滚动，delta 正值向上（一格 = 1）。
ScrollToEnd(id)滚到底；流式内容贴底用它。
ScrollAxis(id, delta, horizontal)指定轴滚动。
ResetScroll(id)丢弃偏移（测试 / 重建界面）。

贴底策略

GO
// 流式追加时：只有用户本来就在底部才跟着滚，
// 别把正在翻历史的用户拽回来。
if ui.ScrollBottomGap("chat") < 24 {
	ui.ScrollToEnd("chat")
}

附录

平台差异

同一份界面代码在三套后端上跑：Windows（Direct2D）、Linux（X11）、Web（canvas + wasm）。

后端

平台后端说明
Windows 10/11Direct2D + DirectWrite主目标：GPU 加速、ClearType、原生 DPI 与 IME。
LinuxX11基础窗口与绘制；部分系统集成能力缺失。
Webjs && wasm + canvas无系统标题栏按钮，无文件对话框。
macOS—尚未实现。

平台相关的行为

  • ui.WindowCaption() 在 Web 上返回 nil；ui.CaptionButtons() 为 false。
  • 文件对话框、拖出文件、剪贴板在未实现的平台上返回错误。
  • Windows 之外的标题栏命中区与 DPI 处理不同，自绘标题栏时只用 ui.TitleBarHeight / ui.CaptionButtonWidth 这两个常量，别写死数字。

构建

BASH
# Windows
go build -o app.exe .
# 只要界面不弹控制台，加 -ldflags="-H windowsgui"（panic 会没有输出）

# Web（GOOS=js GOARCH=wasm）
GOOS=js GOARCH=wasm go build -o app.wasm ./app
附录

已知限制

这些是当前实现里会碰到、但不会报错的边界，写界面前先看一眼。

布局

  • 颜色 A == 0 表示未设置，画不出全透明。
  • Top: 0 之类的零偏移需要 Inset 位标志才生效。
  • Box 的子节点叠在一起，不是文档流。
  • 文本节点高度不够会裁字形下半；给 Height 时按字号 × 1.4 以上估。

输入

  • Scroll / Select / 编辑框的内部状态按 ID 存，ID 变了状态就丢。
  • Select 的开合是进程级 map，测试要自己 SetSelectOpen(id, false) 收尾。
  • OnClick 不冒泡：父子都绑了只会触发最上层那个。

平台

  • 窗口固定 WS_OVERLAPPEDWINDOW：没有「禁止最大化 / 禁止缩放」的开关，固定尺寸小窗被拉大时内容留在原位。
  • Web 上没有系统标题栏按钮与文件对话框。
  • macOS 后端未实现。

性能

  • Continuous(true) 每帧重建整棵根组件，动画之外的场景别开。
  • 超长 Markdown / 大列表放进 Scroll 只是裁剪绘制，节点仍然全部参与布局；上万行要自己做分页或虚拟滚动。
  • 文本测量有跨帧缓存，但每次新字符串仍会问一次后端。
