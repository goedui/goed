# 自定义组件说明

引擎标签用一层 `ui.Props`：`Style` 保持嵌套，组件语义字段在第一层，不套 `Attrs`。

两条 API 分开：

| | 谁用 | 第二个参数 |
|---|---|---|
| 引擎标签 | `ui.HStack` / `ui.Button` / `ui.Input` / `ui.Select` … | `ui.Props{Style, ID, OnClick, …}` |
| 应用组件 | `ui.H(editor.View, …)` | 组件自己的 `editor.Props`（强类型，不嵌 `ui.Props`） |

不要把 `ui.Props` 当成 TS 的 `ComponentProps<'div'>` 嵌进业务组件契约里。

---

## 1. 引擎标签：`Style` 嵌套，属性一层

`Style` 单独一块，把布局/外观和组件属性隔开。类型打架的（`Value`、`OnChange`、`Items`）用 `any`。

```go
type Props struct {
    Style Style // Flex Width Height Padding Gap Align Color Background …

    Key, ID, Label, Placeholder, Variant, Title string
    Disabled, Selected, Password, Compact, Multiline bool

    OnClick   func()
    Value     any // string | bool
    OnChange  any // func(string) | func(bool)
    OnInput   func(string)
    OnKeyDown KeyHandler
    OnClose   any
    Items     any // []string | []Tab | []Menu
    Data      []byte
}
```

调用：

```go
ui.HStack(ui.Props{Style: ui.Style{Flex: 1, Align: ui.Stretch}, ID: "workspace"},
    ui.Select(ui.Props{
        ID: "size", Value: size, Items: widgets.SizeChoices(),
        Disabled: s.busy,
        OnChange: func(v string) { s.setSize(v) },
    }),
    ui.Switch(ui.Props{
        ID: "countToggle", Value: s.countOn, Disabled: s.busy,
        OnChange: func(on bool) { s.countOn = on },
    }),
)
```

规则：

- `OnClick` 只表示这块 DIP 矩形可点（命中测试）。不是 Vue `@click`，不会变成组件 emit。
- `OnChange` / `OnInput` / `OnKeyDown` 是控件语义回调，字段在 `Props` 第一层。
- 不公开 `Attrs` / `Extra`。控件私有键（`onPointerDown`、`_body`）由控件 `init` 直接写节点。
- `Disabled` 零值 `false` = 可用。不要同时留 `Enabled`。
- `Value` 为 `nil` 表示没设。Switch 用 `Value: true/false` + `OnChange: func(bool)`；Select 用 `Value: "…"` + `OnChange: func(string)`。

---

## 2. 应用组件：`ui.View[T]`

`T` 是契约。不嵌 `ui.Props`。需要透传到根上的布局（如 `Flex`）在 `T` 里显式写，由组件自己赋给根节点。

`setup` 只执行一次。`p()` 每帧返回最新的 `T`，不要在 setup 里把 `T` 拷一份用到结束。

```go
func View[T any](setup func(ctx *SetupContext, p func() T) func() *VNode) *ComponentDef
```

`H(View, T{…})` 只接受这个 `T`。`CreateApp`、实例缓存、Key 调和沿用 `*ComponentDef`。

`OnClick` **不会**从 `T` 自动落到根上。要整块可点，组件自己写 `node.OnClick`。

---

## 3. 组件方示例

```go
package editor

import "github.com/goedui/goed/ui"

// Props 是 Editor 的契约，对应 TS 的 interface EditorProps。
// 根据特性决定是否嵌入 ui.Props。
type Props struct {
    Flex   float32
    Path   string
    Focus  bool
    OnSave func(content string)
}

var View = ui.View(func(ctx *ui.SetupContext, p func() Props) func() *ui.VNode {
    s := newState()
    s.revision.Bind(ctx.Invalidate)
    ctx.OnUnmounted(func() { ui.ResetInputState(idEditor) })

    first := p() // setup 时读一次：启动参数
    s.openAtStart = first.Path
    s.focusOnStart = first.Focus

    return func() *ui.VNode {
        cur := p() // 每帧最新
        s.onSave = cur.OnSave

        node := s.render() // 内部仍用 ui.Textarea / ui.MenuBar
        node.Style.Flex = cur.Flex
        return node
    }
})
```

内部拼树仍走引擎标签：

```go
func (s *state) textarea() *ui.VNode {
    return ui.Textarea(ui.Props{
        Style: ui.Style{Flex: 1, Padding: 8, FontFamily: "Consolas", FontSize: s.fontSize},
        ID: idEditor, Value: s.doc.Text, Borderless: true,
        OnInput: func(v string) { s.markEdited(v) },
    }).WithKey(idEditor)
}
```

保存时调契约回调，不是 `OnClick`：

```go
func (s *state) save() {
    // …写盘…
    if s.onSave != nil {
        s.onSave(s.doc.Text)
    }
}
```

无状态小组件可以更短：

```go
type BadgeProps struct {
    Label string
    Hot   bool
}

var Badge = ui.View(func(_ *ui.SetupContext, p func() BadgeProps) func() *ui.VNode {
    return func() *ui.VNode {
        cur := p()
        bg := ui.RGB(240, 240, 240)
        if cur.Hot {
            bg = ui.RGB(59, 166, 235)
        }
        return ui.Button(ui.Props{Style: ui.Style{Background: bg}}, cur.Label)
    }
})
```

## 4. 调用方示例

```go
func NewApp(path string) *ui.ComponentDef {
    return ui.Component(func(_ *ui.SetupContext) func() *ui.VNode {
        return func() *ui.VNode {
            return ui.H(editor.View, editor.Props{
                Flex:  1,
                Path:  path,
                Focus: true,
                OnSave: func(content string) {
                    // 可选：宿主侧收保存结果
                },
            })
        }
    })
}
```

编译器会拦住：漏 `Path`、`OnSave` 写成 `func()`。

根应用仍可用 `ui.Component`（没有对外契约）。只有「被别人 `H` 进去」的组件才值得 `View[T]`。

---

## 5. 对照

| | 引擎标签 | 自定义组件 |
|---|---|---|
| 参数 | `ui.Props{Style, ID, …}` | 自己的 `T` |
| 点击矩形 | `OnClick` | 默认没有；组件自己绑 |
| 值变化 | `OnChange any` | `OnSave func(string)` 等具名字段 |
| 布局 | `Style.Flex` | `T.Flex`，组件写到根 `Style` |

---

## 6. 皮肤包装

给引擎控件填默认值的皮肤（色板、圆角、图标）可以嵌 `ui.Props`，透传布局字段：

```go
type EmptyProps struct {
    ui.Props // 仅此处允许嵌：皮肤要透传布局
    Title, Hint, Icon string
}
```

业务组件（Editor 这类）禁止嵌 `ui.Props`——否则 `OnClick` 会 fallthrough 到根，整块编辑区变成按钮。

有独立业务字段的组合组件用自己的结构体，不用位置参数：

```go
type ReferenceUploadProps struct {
    Name    string
    Data    []byte
    Enabled bool
    Upload  func()
    Remove  func()
}

func ReferenceUpload(p ReferenceUploadProps) *ui.VNode { … }
```
